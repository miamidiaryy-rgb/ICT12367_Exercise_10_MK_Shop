# แบบฝึกหัดที่ 10: แก้ไขระบบสั่งอาหารร้าน MK (เพิ่มประเภทสินค้า + CRUD)

รายวิชา **ICT12367 การใช้กรอบงานสำหรับการพัฒนาเว็บแอปพลิเคชันเพื่อความปลอดภัย**

## ฟีเจอร์ที่พัฒนาเพิ่มตามแบบฝึกหัด
1. **ตารางประเภทสินค้า (`categories`)** ในฐานข้อมูล `db_mk_shop` เก็บ `category_id` และ `category_name` (เนื้อสัตว์, ผัก, เครื่องดื่ม)
2. **หน้าจัดการประเภทสินค้า (`CategoryManager.vue`)** สามารถ แสดง เพิ่ม แก้ไข และลบประเภทสินค้าได้ครบ (CRUD)
3. **หน้าจัดการข้อมูลสินค้า (`ProductManager.vue`)** เพิ่มคอลัมน์ `ประเภท` ในตารางสินค้า ตัวกรองประเภทสินค้า และช่องเลือกประเภทสินค้าในฟอร์มเพิ่ม/แก้ไขสินค้า
4. **หน้าสั่งซื้อสินค้าของลูกค้า (`CustomerMenu.vue`)** เลือกโต๊ะ และกรองดูสินค้าตามประเภท (`เนื้อสัตว์`, `ผัก`, `เครื่องดื่ม`, `ทั้งหมด`) พร้อมปุ่มสั่งซื้อ

## วิธีติดตั้งและรันโปรเจกต์
1. นำเข้าไฟล์ `database/mk_shop.sql` ลงใน MySQL / phpMyAdmin
2. รัน PHP API:
   ```bash
   php -S localhost:8006
   ```
3. รัน Vue.js Front-end:
   ```bash
   npm install
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ `http://localhost:5181`
